## 七情感元素徽章

1. **愛・赤心**
   - 意義：連結、羈絆、溫暖
   - 遊戲性：治療、支援、保護、bond 增幅
   - 色調：赤紅 + 金色光
   - 代表圖示：心形（來自 reference 27DE...）

2. **勇・炎志**
   - 意義：勇氣、行動、燃燒意志
   - 遊戲性：攻擊、突破、主動技能、戰鬥爆發
   - 色調：火焰橙 + 紅
   - 代表：焰尾狐相關進化

3. **信・金剛**
   - 意義：信念、堅定、不動
   - 遊戲性：防禦、抗性、穩定、boundary 抵抗
   - 色調：金黃 + 土褐
   - 代表：金剛 / 土系守護者

4. **和・青木**
   - 意義：和諧、治癒、自然共鳴
   - 遊戲性：恢復、棲地修復、探索增益、自然事件
   - 色調：翠綠 + 木質
   - 代表：青葉麋鹿 / VineTwist

5. **智・玄水**
   - 意義：智慧、洞察、流動
   - 遊戲性：探索、判斷、資訊解析、記憶解析
   - 色調：深藍 + 玄
   - 代表：水晶海馬 / IceTalon 類

6. **憶・幽影**
   - 意義：記憶、預見、幽暗
   - 遊戲性：memory echo、特殊事件觸發、暗影 / 預知技能
   - 色調：幽紫 + 銀灰
   - 代表：夢行領主相關、幽影元素

7. **陰陽・太極**
   - 意義：平衡、無極、轉化
   - 遊戲性：屬性轉化、平衡加成、終階進化條件、混沌抵抗
   - 色調：黑白 + 太極圖案 + 青金
   - 代表：reference 內的太極魔法陣 + 終階形態

---

## 系統用途

- **夥伴性格**：初始情感傾向決定成長路徑
- **進化條件**：達到特定徽章共鳴或收集數量可解鎖進化
- **技能傾向**：戰鬥中不同徽章影響技能效果與共鳴技
- **Soul Talk 情緒轉化**：輸入情緒可轉化為對應徽章經驗
- **棲地痕跡**：長期情緒會在環境中留下對應徽章視覺
- **UI 呈現**：Codex、HUD、Action Sheet、進化頁均需展示徽章
- **Codex 分類**：角色可標記主要情感元素

---

## 設計原則

- 7 種徽章不是簡單的「屬性克制」，而是情感狀態的具象化。
- 必須與傳統屬性（火水木金土 + 雷暗等）混合使用，而非取代。
- 視覺必須對齊 R2_VISUAL_BIBLE.md 的「情感元素徽章」描述與 reference/emotional-emblems/ 內的圖。
- 不可醫療化：所有描述維持「遊戲虛構機制，讓夥伴更真實」。
