# R2_FACTION_BIBLE.md — Nexus Link R2 陣營設定與視覺語言

> 來源：R2 Master Handoff v1.0 第 12 節 + 既有 R2_CANON_REGISTRY.md 與 reference 整理結果。
> 三大陣營：Heartspark Council（玩家守護者）、Black Iron Hackers（敵對/複雜）、Chaos Rift（虛空崩壞）。

---

## 1. Heartspark Council / 心輝議會

**定位**：玩家守護者陣營。

**美術語言**：
- 自然、光、生命、元素共鳴
- 柔和光效
- 石台 / 魔法陣 / 生態紋路
- 色調：翠綠、柔藍、暖金、木質棕 + 發光粒子
- 形狀：圓潤、有機曲線、藤蔓/葉脈/木紋/石紋

**代表夥伴 / 守護者**（來自 reference 52CF...）：
- ThunderPup（雷之守護者）
- IceTalon（水之守護者）
- FlameFlicker（火之守護者，焰尾狐相關）
- StoneShard（土之守護者）
- VineTwist（木之守護者，青葉麋鹿相關）

**用途**：
- 玩家可選夥伴
- 陪伴、成長、進化、地圖探索
- 棲地共鳴與守護機制

---

## 2. Black Iron Hackers / 黑鐵駭客

**定位**：敵對或複雜陣營（秩序 + 侵核）。

**美術語言**：
- 金屬、工業、機械、侵核、資料污染、秩序/駭入
- 黑鐵灰 + 橘紅霓虹 + 冷藍電路 + 腐蝕綠 + 銹跡
- 形狀：稜角、裝甲板、齒輪、電路、數據碎片、硬邊、侵蝕紋理

**代表**（來自 reference）：
- 深淵獅帝（Abyss Lion Emperor，黑鐵標記）
- 聖金龍神（Sacred Golden Dragon God，秩序核心）
- 黑鐵哥吉拉式機械獸（96x96 pixel spec 圖 623D...）
- Chrome Serpent、Hazard Roar 等

**用途**：
- 敵人 / Boss
- 地圖威脅
- faction conflict
- 玩家可選的「危險」路線（複雜陣營）

---

## 3. Chaos Rift / 混沌裂隙

**定位**：虛空、錯誤記憶、恐懼與崩壞陣營。

**美術語言**：
- 紫黑、錯誤資料、眼球、蝴蝶/觸手、虛空核心、心理 glitch、記憶崩壞
- 色調：深紫、血紅、腐黑、故障藍、閃爍斷裂
- 形狀：不規則、扭曲、裂口、靜電噪點、記憶碎片

**代表**（來自 reference）：
- 虛土領主（Voidsoil Lord）
- 血紅領主（Blood Red Lord）
- 夢行領主（Dream Walker Lord）
- 旋渦領主（Vortex Lord）
- 深淵領主類型

**用途**：
- Chapter boss
- late-game threat
- emotional corruption
- memory collapse events
- 心理與現實邊界崩壞體驗

---

## 4. 陣營交叉與設計原則

- 一個角色可同時屬 boss + 某 faction（如深淵獅帝同時是黑鐵 + 水暗）。
- 玩家陣營（Heartspark）強調共鳴與守護。
- 敵對陣營強調侵蝕、污染、崩壞，但仍需維持整體 Cyber-Taoism 基調（不可純暗黑無光）。
- 所有 faction 視覺必須對照 R2_VISUAL_BIBLE.md 的「派系視覺語言」章節。
