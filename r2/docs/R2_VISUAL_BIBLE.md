# R2_VISUAL_BIBLE.md — Nexus Link R2 視覺聖經

> 定義 R2 的視覺語言、不可退化紅線、派系美術風格、UI 規範與 pixel art 鐵律。
> 來源：r2/assets/reference/ 整理後的 visual-north-star/、codex-ui/、faction-style/*、pixel-asset-specs/ 等。
> 目標：讓所有後續產出（包含 Fable 5 產圖）都能對齊「Cyber-Taoism（賽博道教）」——科技感與道家靜謐並存，而非普通手遊 / RPG / 心理 App。

---

## 1. R2 主畫面風格（Visual North Star）

**核心畫面元素（來自 visual-north-star/ 多張 home screen）**：
- **9:16 手機直式構圖**：單一主角（灰影貓）置中偏下，營火在其前方或側邊，形成 ritual 焦點。
- **夜湖棲地**：深藍/靛青夜色、湖面月光倒影、遠山剪影、微光粒子（藍/紫/白）、星空。
- **灰影貓**：灰白條紋貓、黃眼、項圈有菱形金色符文、坐在石台或魔法陣上、姿態安靜觀察或回望玩家。
- **HUD 層**：
  - 頂部：Lv、名稱「灰影貓 / NEXUS CORE」、金幣 + 水晶數量、通知/設定 icon。
  - 左上：核心資訊卡（Bond 親密、Mood 心情、Energy 能量、Trust 信任）+ 今日任務入口。
  - 右上：快捷資訊（信箱、通知、設定）。
  - 底部：4 宮格主導航（探索 羅盤、照顧 手心、成長 葉子、記憶 書本），帶 active 狀態與 icon。
- **Soul Talk 面板**：浮動半透明玻璃框、頭像 + 對話氣泡 + 語音波形、展開箭頭。
- **氛圍道具**：石圍營火（火星上揚）、月亮、魔法陣（同心圓 + 符文）、藍色晶體、燈籠、藍蝶粒子、湖面反光。
- **光影與粒子**：月光為主光源 + 營火暖光 + 微光粒子 + 低頻率呼吸式 glow。

**氛圍關鍵詞**：靜謐、儀式感、月光、湖畔、守護、共鳴、Cyber-Taoism。
**禁止**：亮色卡通、普通日間手遊 UI、粉紅愛心、醫療清新風、戰鬥特效過度、 crowded 元素。

## 2. 圖鑑 UI 風格（Codex UI）

**核心元素（來自 codex-ui/ 與多張 5 階段 codex 頁）**：
- **五階段橫向進化 layout**：幼年期（BABY）→ 成長期（CHILD）→ 成熟期（ADULT）→ 完全體（PERFECT）→ 究極體（ULTIMATE），用 > 箭頭連接，每格有角色立繪 + 階段標題（中英）。
- **雷達能力圖**（六角或三角）：力量、防禦、速度、智慧、情感、治癒 等軸，填色依屬性。
- **情感元素徽章**：六角盾形或圓形、對應 7 元素色（赤心紅、炎志橙、金剛黃、青木綠、玄水藍、幽影紫、太極青白），內有簡化圖示 + 文字。
- **完全體 / 究極體展示框**：加大尺寸、特效外框（火焰、雷電、夢境粒子、虛空觸手等）、專屬 lore 文字。
- **中英雙語標籤**：中文大標題在上或側，英文小字（BABY / CHILD... 或屬性）。
- **深藍 cyber UI**：#0a0f2e 深底 + 霓虹藍/金/紫邊框 + 玻璃半透明 panel + 細線條科技紋理 + 微光粒子。
- **屬性色 accent**：火=橙紅、水=藍、雷=青紫、木=綠、土=褐、暗=深紫、混沌=紅黑等。不可用粉紅、亮黃、卡通漸層。
- **其他**：角色 lore 短文（象徵意義）、數碼寶貝式介紹框、共鳴/屬性 icon。

**禁止**：普通 RPG 圖鑑（木質/紙張風）、療癒 App 清新卡片、過度寫實 3D render、純賽博龐克霓虹無道家靜謐。

## 3. 派系視覺語言（Faction Style）

### heartspark-council（心輝議會）
- **美術語言**：自然、守護、柔和、生命、光、元素共鳴。
- **色調**：翠綠、柔藍、暖金、木質棕 + 發光粒子。
- **形狀**：圓潤、有機曲線、藤蔓/葉脈/木紋/石紋、溫和 glow。
- **代表圖**：52CF... 五守護者 3 視圖（ThunderPup 雷、IceTalon 冰晶狼、FlameFlicker 火狐、StoneShard 土熊、VineTwist 木鹿）、石台、64 PPU 風格。
- **氛圍**：共生、守護、環境同步（與棲地共鳴）。

### black-iron-hackers（黑鐵駭客）
- **美術語言**：金屬、機械、工業、侵核、資料污染、秩序/駭入。
- **色調**：黑鐵灰、橘紅霓虹、冷藍電路、腐蝕綠、銹跡。
- **形狀**：稜角、裝甲板、齒輪、電路、數據碎片、硬邊、侵蝕紋理。
- **代表圖**：623D... 96x96 黑鐵哥吉拉龍 4 階段（完整 prompt + spec）、IMG_832x 系列綠焰電路狐。
- **氛圍**：侵入、污染、控制、冰冷秩序中帶破壞美學。

### chaos-rift（混沌裂隙）
- **美術語言**：虛空、錯誤記憶、恐懼、裂隙、混沌、心理 glitch。
- **色調**：深紫、血紅、腐黑、故障藍、閃爍斷裂。
- **形狀**：不規則、觸手、眼球、漩渦、裂口、扭曲、靜電噪點、記憶碎片。
- **代表圖**：夢行領主（紫蝶虛空）、漩渦領主、虛土領主、血紅領主、深淵獅帝部分。
- **氛圍**：不安、侵蝕、現實邊界崩壞、夢魘與恐懼具象化（但仍為遊戲虛構）。

**派系交叉**：一個角色可同時屬 boss + 某 faction（如深淵獅帝標記黑鐵）。

## 4. Pixel Art 規則（來自 pixel-asset-specs/ 與所有 codex 內小圖）

**鐵律**（來自 623D、11A2、5C7C、B3BE 等）：
- **尺寸明確**：32x32（幼年/ icon）、64x64（成長/成熟）、96x96（高階/展示）。
- **PPU（Pixels Per Unit）**：常見 64 PPU，角色尺寸與 grid 對齊。
- **透明 PNG**：必須無背景、無 checkerboard 殘留。
- **Pixel Perfect**：sharp edges、no anti-aliasing、nearest-neighbor 採樣。
- **無 blur / 無插值**：永遠。
- **Sprite 用途**：Unity Sprite / 角色圖鑑 / 進化展示 / 實際遊戲 sprite sheet 皆需符合。
- **Prompt 工程**：高階 spec 圖會附詳細 prompt（pose、lighting、color、style、no blur...）。
- **Animation pipeline**：單張 reference 只是概念，實際需拆成 frames + animations.json。
- **Bottom-center baseline**：角色腳底置中，方便 Pixi 定位。
- **禁止**：在 sprite 內 baked UI 文字、過度陰影、寫實光影、漸層、模糊邊緣。

**範例來源**：
- 623D：96x96 4 階段 + 完整 prompt 工程 + 共用規格清單。
- 11A2 / 9FFE：64 PPU + 3 視圖 + 色票 + 設計重點。
- 5C7C：不同進化階段使用不同基礎尺寸。
- 2AF2 等：透明背景多 pose 參考。

## 5. UI 玻璃感 / 深藍 cyber / 屬性色 accent

- **玻璃 / 半透明**：Soul Talk 面板、HUD 卡片、導航按鈕使用 blur + 低 opacity + 細邊框 + 內發光。
- **深藍 cyber 底**：主背景 #0a0f2e ~ #0d1426，輔以深靛、黑。
- **線條與 glow**：細科技線 + 低頻率脈動 glow（藍/金/紫/白）。
- **屬性 accent**：火用暖橘紅、雷用青紫、水用藍、木用翠綠、暗用深紫紅。accent 只用在邊框、徽章、雷達填色、重要文字。
- **字體與層級**：中英混排、標題粗、說明細、層級清楚（不可雜亂）。

**不可變成**：
- 普通手遊 UI（亮色、圓角過度、emoji 過多、扁平卡片）。
- 普通 RPG（木頭/石頭/羊皮紙質感、過多裝飾花紋）。
- 心理治療 App（粉彩、雲朵、過度柔和無科技感、醫療 icon）。

**Cyber-Taoism 精髓**：高科技介面包裹道家靜謐、月湖、儀式、共鳴。科技是工具，道是氛圍。

## 6. 總紅線（永遠禁止）

- 不可把 reference 圖直接當 runtime sprite / background / UI 貼圖使用。
- 不可在 sprite 內 baked 任何文字（HUD 文字必須 DOM / CSS / 獨立 texture）。
- 不可使用 linear 插值、blur、anti-aliasing。
- 不可讓 UI 退化成普通手遊 / 療癒 App / 戰鬥遊戲風格。
- 不可忽略 9:16 與單一主角 + ritual 焦點的主畫面結構。
- 所有新產圖必須先對照本文件 + R2_REFERENCE_ASSET_INDEX.md 審查。
