# UI Panels

This folder stores reusable panel art for Nexus Link UI.

Expected files:

- `UI_CoreHudCompact.png` — collapsed top-left NEXUS CORE frame
- `UI_CoreHudExpanded_Prototype.png` — expanded top-left NEXUS CORE frame with stat rows
- `UI_SoulTalkPanel_Compact.png` — compact floating SOUL TALK dialogue panel frame

Guidelines:

- Use PNG format.
- Prefer true transparent background with alpha channel.
- Keep text out of the image; HTML/CSS should render dynamic text.
- Keep panels readable on mobile screens.
