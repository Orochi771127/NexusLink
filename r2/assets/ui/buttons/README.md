# UI Buttons

This folder stores reusable navigation button art for Nexus Link UI.

Expected files:

- `BTN_Explore.png` — bottom navigation button for Explore
- `BTN_Care.png` — bottom navigation button for Care
- `BTN_Growth.png` — bottom navigation button for Growth
- `BTN_Memory.png` — bottom navigation button for Memory

Guidelines:

- Use PNG format.
- Prefer true transparent background with alpha channel.
- Keep text out of the image; HTML/CSS should render labels.
- Keep icons readable at small mobile sizes.
