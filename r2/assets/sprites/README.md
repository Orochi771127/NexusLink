# Sprite Assets

This folder stores character sprite sheets and animation assets.

Recommended usage:

- one subfolder per companion or creature
- one file per animation state
- transparent PNG sprite sheets for PixiJS

Example:

```text
assets/sprites/flametail-fox/idle.png
assets/sprites/flametail-fox/happy.png
assets/sprites/flametail-fox/tired.png
assets/sprites/flametail-fox/defensive.png
```
