# Human Approval Checklist

## Review Target

- Character id: `<character-id>`
- Action id: `<action-id>`
- Sheet path: `<processed-sheet.png>`
- Preview path: `<preview.gif-or-png>`
- Validation report: `<validation-report.json>`

## Identity

- [ ] Character identity matches the approved lock spec.
- [ ] Character does not drift into another species, faction, life stage, or alternate version.
- [ ] Overall silhouette remains recognizable in every frame.

## Face And Eyes

- [ ] Face shape matches the approved identity.
- [ ] Eye color, eye shape, and expression remain consistent.
- [ ] Expression supports the action without changing the character's personality.

## Palette

- [ ] Base palette matches the lock spec.
- [ ] Glow colors and highlights match the lock spec.
- [ ] No unintended alternate color variant appears.

## Signature Markings

- [ ] Required markings are present.
- [ ] Marking placement remains stable across frames.
- [ ] Markings read as the intended material or energy type, not a different motif.

## Tail And Special Anatomy

- [ ] Tail or special anatomy matches the lock spec.
- [ ] Special anatomy does not shrink, disappear, or change material.
- [ ] Special anatomy remains consistent across all frames.

## Action Readability

- [ ] The intended action is readable.
- [ ] Motion is clear without breaking identity.
- [ ] The action does not add unapproved props, UI, weapons, armor, or scene elements.

## Frame Consistency

- [ ] Every frame uses the same character proportions.
- [ ] Frame-to-frame scale remains consistent.
- [ ] No frame has missing limbs, duplicated anatomy, or off-model drift.

## Baseline And Anchor

- [ ] Baseline is stable across frames.
- [ ] Bottom-center anchor is preserved.
- [ ] Feet or contact points do not slide unless the action intentionally moves.

## Background And Baked Elements

- [ ] Final sheet has transparent background.
- [ ] No white background.
- [ ] No UI.
- [ ] No text.
- [ ] No scene.
- [ ] No pedestal, card frame, catalog frame, or display stand.

## Style

- [ ] Style matches illustrated / painterly / high-detail companion production.
- [ ] No unintended chunky pixel art drift.
- [ ] No nearest-neighbor or pixel-perfect assumptions are required for clarity.

## Decision

- [ ] Approve for runtime promotion after validator pass.
- [ ] Revise and regenerate.
- [ ] Reject and do not use.
