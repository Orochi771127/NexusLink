# Flametail Fox Prompt Templates

Use these prompts to generate the first companion assets for Nexus Link.

---

## Single Companion Image

```text
Create a single transparent PNG character sprite for Nexus Link.

Character:
Flametail Fox, a small AI companion monster with an orange-red fox body, warm eyes, a flame-shaped head tuft, white chest fur, and a glowing flame tail. It should feel like a personal companion, not an enemy.

Style:
- clean 2D pixel art
- cozy mobile game mascot
- soft emotional fantasy
- readable silhouette
- dark pixel outline
- warm orange and golden fire palette
- subtle cyan digital glow accents
- no text
- no background
- no UI
- no religious symbols

Composition:
- 3/4 front view
- full body visible
- centered
- calm and present
- cute but not childish

Technical:
- transparent background
- 512x512 px
- PNG
- readable when displayed at mobile scale
```
