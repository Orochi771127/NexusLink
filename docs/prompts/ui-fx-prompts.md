# UI and FX Prompt Templates

Use these prompts to generate interface icons and atmosphere effects for Nexus Link.

---

## Status Icon Pack

```text
Create a 5-icon pixel UI pack for Nexus Link.

Asset names:
- bond.png
- trust.png
- mood.png
- energy.png
- memory.png

Icon concepts:
1. Bond: warm heart flame
2. Trust: small glowing shield
3. Mood: soft emotional orb or moon-like face
4. Energy: small fire spark
5. Memory: glowing crystal light mote

Style:
- pixel art UI icons
- transparent background
- soft glow
- readable at small size
- consistent visual language
- cozy sci-fantasy
- no text
- no complex symbols

Technical:
- 64x64 px each
- transparent PNG
- consistent padding
- mobile UI readable
```
