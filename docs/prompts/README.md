# Prompt Templates

This folder stores reusable asset-generation prompts for Nexus Link.

Use these prompts with Codex-compatible image workflows, agent-sprite-forge, ChatGPT image generation, Gemini, or other asset generation tools.

Prompt files are organized by asset category:

```text
flametail-fox-prompts.md
lake-camp-prompts.md
ui-fx-prompts.md
```

Keep prompts aligned with the current product direction:

- AI companion emotional habitat
- mobile-first vertical layout
- 2D pixel art / soft pixel hybrid
- readable silhouettes
- low visual noise
- emotional atmosphere over combat spectacle
