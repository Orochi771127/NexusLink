# Nexus Link Product Opportunities

> **Status:** Non-canonical reference layer  
> **Authority:** Below `docs/strategy/NEXUS_LINK_MASTER_CANON_v3.1.md`  
> **Purpose:** Preserve and evaluate broad-market tool concepts without changing the approved identity of Nexus Link.

## Operating Rule

This directory is an **incubator**, not a committed roadmap. An idea may be documented here even when it is unsuitable for the current game. Nothing in this directory authorizes implementation by itself.

When any statement conflicts with the Master Canon, Design Bible, Runtime Canon, `CLAUDE.md`, `AGENTS.md`, or `ACCEPTANCE.md`, the higher-authority document wins.

## Decision States

| State | Meaning |
|---|---|
| `IDEA` | Unvalidated concept. No implementation authority. |
| `RESEARCH` | Needs evidence, user interviews, prototype, or technical spike. |
| `EXPERIMENT` | Time-boxed test with explicit success and kill criteria. |
| `CANDIDATE` | Passed evidence gate; still requires Canon and owner approval. |
| `APPROVED` | Explicitly added to an authoritative roadmap or task pack. |
| `REJECTED` | Contradicts product identity, economics, safety, or maintenance limits. |
| `SPINOUT` | Better treated as a separate product or repository. |

## Non-Negotiable Boundary

Nexus Link is currently an emotional habitat companion game. It is not automatically a general productivity suite, wellness platform, finance coach, healthcare product, or universal Life OS.

A broad-market tool belongs inside Nexus Link only when it strengthens the companion relationship, habitat presence, meaningful memory, shared ritual, or chapter experience. Otherwise it should remain research, become an optional external integration, or be evaluated as a future spinout.
