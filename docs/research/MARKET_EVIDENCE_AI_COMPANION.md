## 0. Executive Summary

1. AI companion / emotional AI / virtual companion 相鄰市場確實快速成長，但各報告對市場定義差異很大，不能直接把整個 AI companion TAM 當成 Nexus Link 可取得市場。
2. 多份市場研究與社群討論都指向同一個產品趨勢：使用者不只想要「會聊天」，而是想要長期記憶、上下文連續性、情緒存在感與低壓力陪伴。
3. 純 romantic / NSFW / mating-oriented companion 產品可能有高初始吸引力，但也有 churn-and-burn 風險；mixed-use 或具備創作、角色扮演、情緒支持與長期記憶的產品可能更適合長期留存。
4. 「16 次 vs 3 次回訪」目前尚未取得可直接驗證的原始來源。此數字暫時不得用於對外 pitch、Steam 頁面或正式商業文件。
5. 使用者對 sycophancy、過度迎合、太黏、無邊界、過度主動通知與 FOMO 類留存機制有明顯反感。這支持 Nexus Link 禁止 streak、紅點、登入獎勵、罪惡感回歸文案的設計方向。
6. 「有邊界的 AI 夥伴」具備差異化潛力，但不是所有玩家都會喜歡。目標玩家應是重視情緒真實、低壓力陪伴、長期關係與敘事沉浸的玩家，而非追求即時迎合或純浪漫刺激的玩家。
7. Nexus Link 最適合的市場定位不是純 AI companion，也不是 AI girlfriend 或傳統電子寵物，而是 narrative emotional habitat game / emotional cozy game 的交集。
8. Nexus Link 的核心市場主張應是：一個會記得你、但不屬於你；會靠近你、但不吞掉你；會因為你如何對待牠而改變的心核生命。
9. 目前最值得優先強化的商業體驗是：First Session Coherence、Initial Bond / 開場定情、Return Echo / 回歸儀式、Habitat Trace / 棲地痕跡，以及視覺一致性。
10. 最大風險不是市場不存在，而是執行時把 Nexus Link 做成普通聊天機器人、普通電子寵物、AI girlfriend、抽卡角色收集或 FOMO 養成遊戲。

## 3. User Need Analysis

### 3.1 短期爽感需求

| 需求 | 代表產品型態 | 風險 |
|---|---|---|
| 浪漫刺激 | AI girlfriend / romantic chatbot | 容易被定位錯誤，與 Nexus Link 不符 |

| 高頻回饋 | streak / login reward / red dot | 形成 FOMO 與壓迫感 |
| 新奇 RP | Character roleplay | 容易流於短期內容消費 |
| 多角色切換 | character collection | 稀釋單一深度關係 |

### 3.2 長期留存需求

| 需求 | 對 Nexus Link 的意義 |
|---|---|
| Long-term memory | 支持 emotionalMemories / habitatTraces / Return Echo |
| Contextual continuity | 支持玩家「我昨天說過的事今天仍存在」 |
| Emotional presence | 支持湖邊棲地、灰影貓姿態與低刺激節奏 |
| Low-pressure companionship | 支持不做 FOMO、不責備、不強迫每天回來 |
| Boundary / subjectivity | 支持 accept / guarded / hesitate / reject |
| Relationship repair | 支持 Emotional Standoff / 不暴力消滅 / 修復關係 |

### 3.3 對 Nexus Link 的產品判斷

Nexus Link 應主打：

> 「被記得，但不被吞掉。」  
> 「被陪伴，但不被操控。」  
> 「牠會因你如何對待牠而改變。」

而不是：

> 「最懂你的 AI。」  
> 「永遠陪你。」  
> 「永遠愛你。」  
> 「你每天都要回來照顧牠。」

## 5. Sycophancy / Clingy AI / Boundary Demand

### 5.1 使用者反感點

社群討論與 AI UX 風險研究常見抱怨：

- AI 太容易肯定使用者。
- AI 缺乏自己的狀態與立場。
- AI 太黏、太主動、像在討好。
- AI 沒有摩擦與關係成長。
- 每次回來都被催促或被 guilt-trip。
- 產品用 streak、紅點、通知、連續登入製造壓力。
- romantic / NSFW 產品短期刺激強，但長期空洞。

### 5.2 Nexus Link 的對應優勢

| 市場痛點 | Nexus Link 對應設計 |
|---|---|
| 過度迎合 | 高 bond 不解除拒絕能力 |
| 無邊界 | touchReaction accept / guarded / hesitate / reject |
| 缺乏記憶 | emotionalMemories / habitatTraces / Return Echo |
| 回歸壓力 | 不責備式 return line |
| FOMO 疲勞 | 不做 streak / daily reward / red dot |
| 純聊天疲勞 | 棲地痕跡、姿態變化、動畫 cue |
| 浪漫誤解 | 主打 emotional habitat，不主打 relationship sim |

### 5.3 邊界作為賣點與風險

「AI 會拒絕」本身不是普遍賣點。它必須被包裝成：

> 牠不是不喜歡你，而是牠有自己的狀態。  
> 你尊重牠，牠會記得。  
> 你越界，棲地會留下痕跡，但不會懲罰你。

可接受的拒絕語氣：

- 「現在不要。退一點。」
- 「我需要一點空間。」
- 「先別急著靠近。」
- 「牠沒有逃開，只是把尾巴收得更近。」

不可接受的拒絕語氣：

- 羞辱玩家。
- 指責玩家人格。
- 暗示玩家造成不可逆傷害。
- 用沉默製造焦慮。
- 用關係撤回作為懲罰。

## 7. Nexus Link Positioning

### 7.1 最推薦定位

#### Primary Positioning

> Narrative Emotional Habitat Game

中文：

> 敘事型情緒棲地遊戲

理由：

- 避免被誤解成 AI girlfriend。
- 避免被誤解成電子寵物。
- 能容納棲地、記憶、回歸、邊界、情緒對峙。
- 適合 Steam / indie game 語境。

#### Secondary Positioning

> Emotional Cozy Game with a Boundary-Aware Companion

中文：

> 一款有邊界夥伴的情緒系 cozy game

理由：

- Cozy game 玩家能理解低壓力、留白、陪伴。
- 但必須避免變成「療癒萬靈丹」或「心理健康產品」。

### 7.2 不建議主定位

| 定位 | 不建議原因 |
|---|---|
| AI Companion | 太廣，容易被歸類為聊天機器人 |
| AI Girlfriend | 完全偏離產品倫理與市場策略 |
| Digital Pet | 會引發照顧、餵食、忽視懲罰期待 |
| Relationship Sim | 容易被期待成戀愛互動 |
| Healing Game | 易被質疑心理健康宣稱 |
| Desktop Companion | 現階段資源不足，且容易變裝飾 |

## 8. Product Strategy Recommendation

### 8.1 Nexus Link 應該主打什麼？

主打：

> 一隻會記得你、但不屬於你；會因為你如何靠近而改變的心核生命。

支撐體驗：

1. First Session Coherence
2. First Trace
3. Return Echo
4. Habitat Trace
5. Boundary-aware Touch
6. Emotional Standoff
7. Initial Bond / 開場定情

### 8.2 Steam 頁面第一句候選

#### 候選 A

> 不是永遠討好你的 AI，而是一個會因為你如何對待牠而真實改變的心核生命。

#### 候選 B

> 在一座會留下情緒痕跡的湖邊，遇見一隻會記得你、也會拒絕你的夥伴。

#### 候選 C

> 這裡沒有任務。只有一隻會記得你來過的心核生命。

#### 推薦

Steam 主頁第一句可用 A。  
Trailer 內第一句可用 C。  
遊戲內 opening line 保持：

> 這裡沒有任務。你可以先待著。

### 8.3 Trailer 前 10 秒

建議順序：

1. 夜湖 / 棲地安靜畫面。
2. 灰影貓在火光旁，不立刻靠近玩家。
3. 玩家輸入一句疲憊短句。
4. 棲地留下一個微弱痕跡。
5. 畫面切到「隔天回來」。
6. 灰影貓姿態不同，營火微亮。
7. 短句出現：  
   > 「上次那點暗光還在營火邊，我沒讓它熄。」
8. Logo：Nexus Link／心核連結。

### 8.4 新玩家前 3 分鐘必須感受到

1. 這裡不是任務列表。
2. 牠不是我的寵物。
3. 我可以說話，也可以只是待著。
4. 我說的話會留下痕跡。
5. 牠會記得，但不會情緒勒索我回來。
6. 我尊重牠的距離，這段關係才會慢慢形成。

### 8.5 現在不該做

- 多角色開場全解鎖
- 角色商城
- 抽卡
- 組隊冒險
- 完整 RPG 戰鬥
- 桌面模式
- PWA
- 後端
- LLM API
- NSFW / AI girlfriend
- streak / daily reward / red dot / login bonus
- 五階全角色量產

### 8.6 最可能提升留存的功能

| 功能 | 原因 |
|---|---|
| Return Echo 打磨 | 玩家回來時能明確感到「牠記得」 |
| Habitat Trace 可視化 | 把記憶做成空間證據 |
| Boundary Feedback | 讓角色主體性可玩 |
| First Session / Initial Bond | 讓玩家知道「這一隻不可替換」 |
| Emotional Standoff | 把衝突與修復做成遊戲差異化 |

### 8.7 會稀釋護城河的功能

| 功能 | 稀釋原因 |
|---|---|
| 多角色全開 | 角色變皮膚 |
| 抽卡 | 角色變商品 |
| 商城賣角色 | 關係商品化 |
| 每日任務 | 低壓力陪伴變義務 |
| 戰力進化 | 人格變化變數值膨脹 |
| 桌面生產模式 | 情緒棲地變效率工具 |
| NSFW / romantic-first | 產品被 AI girlfriend 市場吞沒 |

## 12. Final Verdict

### 12.1 Conservative Verdict

Nexus Link 的市場方向有明確機會，但目前仍屬高執行風險產品。市場對 AI companion、情緒陪伴與記憶存在感有需求，但 Nexus Link 是否能吃到這個需求，取決於它能否在前 3 分鐘內讓玩家理解「這不是電子寵物、不是聊天機器人、不是 AI girlfriend，而是一段會留下痕跡的關係」。

### 12.2 Balanced Verdict

Nexus Link 的「有邊界、會記得、低壓力回歸、情緒棲地」與目前 AI companion / emotional cozy game 相鄰市場趨勢吻合。若能持續收斂 First Session、Return Echo、Habitat Trace、Boundary Feedback 與視覺一致性，具備差異化潛力。最大風險是被錯誤定位或執行時滑向普通養成、普通聊天或角色收集。

### 12.3 Aggressive Product Thesis

Nexus Link 有機會成為「被安靜記得，卻不被吞掉」這類情感需求的代表作。它不是跟 Replika 或 Character.AI 比聊天深度，而是把 AI companion 的記憶與存在感轉化成可見棲地、可玩邊界、回歸儀式與長期人格變化。若執行成功，它的護城河不是模型，而是關係設計。

## 13. Five-Angle Evaluation

### 13.1 投資人角度

有市場趨勢與差異化敘事，但目前需要證明實際留存。短期投資風險高，因為產品不走高刺激、NSFW 或抽卡變現。中長期若 demo retention 證明「低壓力回歸」有效，會有獨特 positioning。

### 13.2 Steam 玩家角度

如果 Steam 頁面與 trailer 能在 10 秒內展示「玩家回來後牠記得」，會有吸引力。若頁面看起來像 AI chatbot、電子寵物或手機養成，會被忽略。

### 13.3 遊戲製作人角度

方向正確，但 scope 必須極窄。應集中打磨第一隻灰影貓、第一棲地、First Session、Return Echo、Boundary Feedback。不要擴張成多角色 RPG。

### 13.4 心理安全角度

Nexus Link 的低壓力、不責備、非 FOMO、有邊界方向較健康。但必須避免醫療宣稱、依賴偵測、guilt-trip 和「痛苦換獎勵」式設計。

### 13.5 獨立開發資源角度

最合理策略是做一個小而深的可玩 demo：一隻主角、一個棲地、一套回歸儀式、一套邊界反應。多角色、桌面模式、LLM、章節擴張都應延後。
