# NexusLink Development Direction

本文件記錄《Nexus Link / 心核連結》目前鎖定的產品發展方向。它用來統一後續企劃、程式、美術、AI 語義與社群溝通的核心判斷。

---

## 1. Core Positioning / 核心定位

《Nexus Link》不是單純的怪獸養成 RPG，也不是普通的聊天型 AI 工具，而是一款：

> 情緒棲地型 AI 夥伴養成遊戲。

玩家進入的不是一個功能選單，而是一個能承接情緒、保存痕跡、被夥伴記得，並隨著互動慢慢變化的安靜世界。

---

## 2. Product Promise / 產品核心一句話

> 不是要玩家立刻變好，而是陪玩家把今天慢慢放下。

這句話是第一階段 MVP 的產品北極星。任何新功能若無法服務這句話，都應延後。

---

## 3. Core Value / 核心價值

現代人不一定缺少道理，更多時候是缺少一個能安全放下情緒的地方。

《Nexus Link》的價值，不是急著分析玩家、糾正玩家，或替玩家下結論，而是讓玩家能把當下的疲憊、難過、焦慮、孤單與混亂，放進一個會回應、會記得、會沉澱的棲地裡。

玩家不是只收到一句安慰，而是能看見自己的情緒在世界中留下痕跡，並透過 AI 夥伴、場景變化、記憶碎片與狀態累積，慢慢被安置與轉化。

---

## 4. Core System Direction / 核心玩法方向

### Emotional Sedimentation / 情緒沉澱系統

玩家輸入情緒後，系統不急著說教，也不立刻給空泛安慰，而是讓情緒進入棲地，成為可被看見、可被保存、可被轉化的存在。

```text
玩家輸入情緒
→ 系統判斷情緒壓力與狀態
→ 棲地產生微變化
→ 心核夥伴給出短句回應
→ 玩家選擇安置方式
→ 情緒轉化為記憶碎片
→ 下次回來時被重新呼應
```

玩家不是來打敗痛苦，而是把痛苦放進一個安全的地方，讓它慢慢變成可以理解、可以共處、可以被重新整理的形狀。

---

## 5. AI Companion Principles / AI 夥伴設計原則

NexusCore / Raphael 不能是無底線的情緒垃圾桶，也不能是冷冰冰的心理分析師。

它應該是：

1. **會陪伴**：能接住玩家當下的情緒。
2. **會記得**：能保存玩家留下的片段。
3. **會變化**：會因互動、信任、疲勞、防衛與羈絆而改變狀態。
4. **有邊界**：不盲目迎合，也不過度懲罰玩家。
5. **不說教**：優先陪玩家安置情緒，而不是急著修正玩家。
6. **不取代現實關係**：它是陪伴與沉澱空間，不是假裝能解決所有人生問題。

---

## 6. Scope Guard / 避免的錯誤方向

現階段不應急著加入：

- 完整戰鬥系統
- 屬性克制
- 多夥伴隊伍
- 大地圖探索
- 背包與裝備
- 複雜任務鏈
- 過度商業包裝
- 完整 LLM 長期記憶系統

這些可以是未來內容，但不是第一階段 MVP 的核心。

---

## 7. MVP Focus / 目前最重要的 MVP

第一階段只做一件事：

> 讓第一棲地真的活起來。

優先完成：

1. 一個湖畔棲地
2. 一隻當前主夥伴，並保留後續夥伴擴充方向
3. 觸摸 / 擁抱反應
4. 心語輸入
5. 情緒狀態改變
6. 記憶保存
7. 棲地 FX 變化
8. 玩家下次回來時感覺「牠還記得我」

---

## 8. Current Companion Direction / 目前夥伴方向

目前敘事與美術方向先聚焦於下列心核夥伴：

- 灰影貓 / Greyshade Cat：第一棲地的當前 runtime 主夥伴。
- 雷霆幼狼 / ThunderPup：後續代表活力、守護與電路生命感的主要夥伴候選。
- 星能小山豬 / Star-Energy Boarlet：後續代表星能、野性、可愛異質感與探索性的夥伴候選。

第一階段仍以單一主夥伴與第一棲地完成度為優先，不因新增候選夥伴而擴張成多角色系統。

---

## 9. Final Direction / 最終發展方向

《Nexus Link》的核心不是做一款更複雜的 RPG，而是建立一個：

> 能承接玩家情緒、保存玩家痕跡，並讓 AI 夥伴與場景共同回應玩家生命狀態的情緒棲地。

玩家不是來完成任務，而是來留下自己。

心核夥伴不是工具，而是一個會陪伴、會記得、會慢慢變化的存在。

棲地不是背景，而是玩家情緒沉澱後形成的內在風景。

《Nexus Link》要做的，是一個可以承接情緒、保存情緒、轉化情緒，並讓玩家再次回來時，看見自己曾經被好好接住的世界。
