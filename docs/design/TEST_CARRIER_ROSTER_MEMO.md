## 1. 這份備忘要解決的問題

有 5 隻角色 —— **焰紋狐 `flame-flicker`（火）／冰晶狼 `ice-talon`（水）／磐石熊 `stone-shard`（土）／青藤鹿 `vine-twist`（木）／晶石兔 `crystal-rabbit`（金）** —— 動畫資產完全就緒，但**在遊戲裡沒有任何新玩家能拿到牠們的路徑**。Owner 想給牠們「章節相遇 + 一起冒險」的用途。本備忘攤開 canon 約束與可行定位，供 Owner 選擇方向。

CLAUDE.md §7 早已把這 5 隻標為「現行 full-runtime 動畫測試載體；不占正式心輝議會五行席位，**最終用途待另案**」。本備忘就是在整理那個「另案」。

## 4. 核心張力：直接走章節相遇會「撞角色」

- 議會五席（守護者）＝金木水火土一組；測試五隻＝**又一組**金木水火土，且目前也掛「心輝議會」。
- 章節相遇/共鳴邀請機制（`maybeMeetChapterCompanion` + `resonanceInviteEngine`）**每章一席、已綁議會五席**。
- 若把測試五隻也塞進同一條線，會出現「心輝議會有兩組金木水火土守護者」——**與 §6.2「每勢力各一組」正面衝突**，也稀釋議會五席的正典地位。

→ 結論：**要用牠們,關鍵不是「接不接解鎖」,而是先給牠們一個「不與議會五席重疊」的身份。** 機制是現成的,身份要先定。

## 5. 方案比較

> 相遇/冒險機制（章節相遇一拍 → 通關取得詢問資格 → 依關係決定是否加入共鳴圈，最多三隻同場對峙）**四個方案都能重用**，差別在「身份、敘事理由、改造成本、canon 影響」。

### 方案 A（建議）— 補上「黑鐵駭客」或「混頓裂隙」空缺五行席，對手→和解→同行
- **定位**：把五隻改隸一個**目前空缺**的勢力五行席，於後段/資料片章節以**對立姿態**登場，關係培養後可和解、加入共鳴圈同行。
- **Canon 依據**：直接填 §6.2 既有空位，**不新增、不牴觸 canon**。
- **相遇/冒險如何接**：完全重用現成機制；「先對立才和解」反而讓「一起冒險」更有重量（契約三：影響而非支配）。
- **改造成本**：中。需重寫 persona / soulTalkTone / description，把「溫暖親人」轉為「侵蝕者的冷硬」或「異常覺醒體的卡死」，或設計成「被拯救／倒戈」的成員。動的是**體驗層資料**（persona 語料、registry 文案），不動地基。
- **風險**：persona 重做工作量；需與現有 Raphael 語料訓練批次協調。
- **地基**：否（純資料/內容層）。

### 方案 B — 維持心輝議會，作「第二波守護者」
- **定位**：不換勢力，設為議會的另一梯隊（例如不同棲地的同源守護者），資料片章節相遇。
- **Canon 依據**：**弱**。§6.2 是「每勢力各一組五行」，同勢力兩組金木水火土需要 Owner 明確擴充 canon 才站得住。
- **改造成本**：低（persona 幾乎不動）。
- **風險**：正典模糊；玩家會問「為什麼有兩隻火屬心輝夥伴」。
- **地基**：否，但**需改 canon 文本**（World Bible），這本身要 Owner 拍板。

### 方案 C — 中立漫遊者（比照灰影貓／星能小山豬）
- **定位**：不屬任何勢力，作旅痕/地圖事件中的偶遇同行者。
- **Canon 依據**：**弱**。§6.2 明寫「唯二中立」；再加五隻中立會稀釋灰影/星能的獨特性。
- **改造成本**：中。
- **風險**：與既有中立設定衝突。
- **地基**：否，但同樣**需改 canon**。

### 方案 D — 保留現狀，延後到商業化章節包
- **定位**：確認為「刻意 park 的 runtime 待命載體」，等 first-session 垂直切片打磨完、進入 §0.6 付費章節包時再啟用。
- **Canon 依據**：**強**。完全順從 CLAUDE.md §0.5「凡不服務首輪連貫的功能一律延後」與 §7「最終用途待另案」。
- **改造成本**：零（現在什麼都不做）。
- **風險**：五隻繼續「用不到」，但這是**受控且刻意**的，不是缺陷。
- **地基**：否。

## 6. 建議

**短期：方案 D（維持現狀、確認為刻意 park）。** 現階段（Pre-Commercial Vertical Slice）主線是首輪連貫，議會五席的章節相遇線本身都還沒完全打通（`chapterRegistry` 註解仍標 CH-5b 未實裝，雖然程式路徑已在）。此時再開第二組五行只會分散火力。

**中期方向：方案 A。** 當要擴充勢力時，讓這五隻補上**黑鐵駭客或混頓裂隙**的空缺五行席，以「對手→和解→同行」登場——這同時（1）給牠們不與議會五席重疊的正典身份、（2）給「一起冒險」一個有重量的敘事理由、（3）100% 重用現成相遇/共鳴機制、（4）不牴觸、不新增 canon。

> 兩者不互斥：現在採 D，把 A 記入 roadmap 作為勢力擴充的首選填法。
