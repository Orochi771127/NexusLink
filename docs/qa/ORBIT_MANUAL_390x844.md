## 路徑（約 10–15 分）

1. **探索入口**  
   - [ ] 探索頁可見「月湖路徑・迴旋」  
   - [ ] 點開後 HUD／底欄不被蓋住，焦點落在可關閉或可選節點的按鈕

2. **路徑圖**  
   - [ ] 月湖五關可見；未解鎖標「尚未亮起」類文案  
   - [ ] Esc／「回到探索」可離開，無卡死

3. **拉動手感**  
   - [ ] 短拉：化身可控、不易秒飛出界  
   - [ ] 長拉：明顯更快／更遠  
   - [ ] 撞擊可讀，單次不會瞬間秒殺到無法辨識連撞

4. **惜敗／撤退**  
   - [ ] 「先撤退」→ 可回路徑圖；無羞辱 win/lose  
   - [ ] 敗北語氣偏陪伴（惜敗），非懲罰 bond

5. **對決（選做）**  
   - [ ] 人機可打完一局；連打過熱會休息提示  
   - [ ] 勝負不改羈絆／信任（存檔前後對照）

6. **無障礙抽查**  
   - [ ] Esc 全程可退  
   - [ ] `prefers-reduced-motion` 下按鈕無誇張彈跳  
   - [ ] canvas 可被鍵盤聚焦（tabindex）

7. **Moonlake Camp Hybrid Spin 證明關（opt-in）**

   - [ ] 三次內能說出短／中／長拉的速度或軌跡差異
   - [ ] 發射前能依虛線預測大致方向；依序碰到 1 → 2 → 3 才亮
   - [ ] 三點全亮後，化身必須慢下來並停在營火圈，不能高速擦過就算完成
   - [ ] 場上無敵方 HP／雜訊血條；結算能說出「記憶回到營火」影響了夥伴台詞或場景微痕

   - [ ] 在接近下一個光點時按脈衝：只有限修正方向，仍須實際掠過光點
   - [ ] 三點全亮後按脈衝：可協助向營火收束／降速，但高速擦過仍不能完成
