# Pack 1 §J Human Score Sheet（五人新玩家）

給 Owner／測試主持：每位**從未玩過 Nexus Link** 的玩家各填一列。不要旁白教機制。

## Session rules

- 約 10–12 分鐘，不要提示「該點哪裡」
- 結束後再問五題（可口頭）
- 動機不可來自獎勵、紅點、登入壓力、愧疚話術

## Questions

1. 這隻角色和普通電子寵物有什麼不同？
2. 你現在知道下一步可以做什麼嗎？
3. 剛才哪個行動改變了角色或世界？
4. 你知道為什麼下次可能值得回來嗎？
5. 你剛才有沒有感到被逼著繼續？
