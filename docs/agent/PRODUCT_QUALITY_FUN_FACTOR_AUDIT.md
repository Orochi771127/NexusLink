## 0. 殘酷版執行摘要

**Nexus Link 的靈魂是真的,但玩家目前只能「讀」到它,不能「感覺」到它。**

系統深度是真實的:會拒絕的夥伴、不可逆的記憶痕跡、四種不懲罰結局的情緒對峙、無 FOMO 的回歸設計 — 這些在代碼裡全部存在且經過驗證。文案品質是 VN 級的。安全脊柱(紅線、safetyShield、邊界系統)在同類產品中罕見。

但把它當一款「遊戲產品」打開,問題立刻暴露:

1. **整個遊戲幾乎是無聲的。** 唯一的聲音是一條循環 BGM(`bgm_nexuslink.m4a`,上限 0.42 音量)。摸貓沒有聲音、心語沒有聲音、痕跡出現沒有聲音、對峙沒有聲音。更糟:設定面板有一條「音效」滑桿(`set.sfx`),`audioManager.js:22` 存了 `sfxVolume`,但**全 `src/` 沒有任何一處播放音效的代碼** — 這是一個控制不存在系統的死 UI,對玩家等同「遊戲壞了」。
2. **夥伴從不主動。** 灰影貓只會回應,永遠不會先走向湖邊、先看你一眼、先說一句話。諷刺的是,整套自主行為基建(`needModel`/`goalManager`/`initiativeCooldown`/`autonomyLoop`)已經建好並通過測試 — 只是沒有任何玩家可見的行為使用它。這是與聊天 app 差異化的最大失分點:Replika 們最會的一招(主動存在感),Nexus Link 有能力安全地做、卻沒做。
3. **回饋幾乎全是文字。** 探索 = 點節點 → 瞬間出一行字。對峙的敵人 = 一個名字,沒有形體。這不是引擎限制 — Pixi 棲地六層渲染、痕跡視覺系統(含現成的 `glitch_noise` 視覺)全部在線。
4. **一處 canon 與代碼的真實矛盾:** Master Canon §86 明令「若先改解鎖數而選角 UI 未就緒,將產生『強制只有一隻、又無選擇畫面』的劣化體驗」— 而 `defaultState.js:67-69` 現在正是只解鎖 `greyshade-cat` 且無初遇選角 UI。代碼跳過了 canon 要求的順序。同時多份文件(AGENTS.md §7「目前 root defaultState 預設解鎖 runtime-ready companions」、Canon §176「六隻全解鎖稀釋」)描述的是**已不存在**的舊狀態 — 文件漂移正在誤導排期。

**結論:讓它變好玩的下一步不是更多 AI,是聲音、主動存在感、和已有系統的可見化。** 工程紀律(4 天連續出貨、10/10 release gate)是資產;把同樣的紀律轉向感官品質,60 天內可以從「令人尊敬的 demo」變成「想給朋友看的遊戲」。

## 過度工程的(相對於今天的玩家影響)

1. **外部智能腳手架**:`src/ai/external/`(gateway、provider adapters、promptFirewall、privacyRedactor)+ preview staging + LangGraph 平行實驗室。存在合理、繼續長大不合理 — 沒有任何玩家向功能在等它。
2. **自我演化管線**(`src/ai/evolution/` 六模組):為 ~200 行語料建 patch-proposal 機器,人手寫更快。凍結即可,不必拆。
3. **QA:內容比例倒掛**:14 個測試 harness + 18 個 QA runner 對 6 個可探索節點。安全 eval 該保留,但**下一個小時該花在內容行數,不是第 15 個 harness**。
4. **agent 工作流文件**:docs/agent 本月新增 7+ 份。邊際新文件已不改變任何行為;ledger + queue 足夠。(本文件是任務指定交付,寫完後同樣適用此條。)

## 設計不足的

1. **夥伴主動存在感** — 基建全備,行為零。(最高優先設計缺口)
2. **每個動作的感官回饋** — 聲音/棲地反應/微動效的系統性缺席。
3. **對峙的視覺身份** — 機制是原創的,呈現是純文字的;原創性被埋沒。
4. **驚喜預算 = 0** — 全部反應確定性、節點結果固定池、無稀有事件、無天氣。「留白」是特性,「完全可預測」不是。canon 允許驚喜,現狀沒有。
5. **30 分鐘後的敘事弧** — 里程碑線之外沒有「第一章」;裂隙(混頓裂隙)是世界內建的懸念,首輪幾乎不可見。

## 可能讓 Nexus Link 特別的

- **會拒絕你的夥伴 + 拒絕後的修復路徑**(尊重獎勵機制)— 沒有任何競品敢做。
- **不可逆的記憶痕跡留在一個「地方」裡** — 記憶有地理位置,這是 Tamagotchi 和聊天 app 都沒有的。
- **穩住裂隙** — 用「陪伴而非消滅」重構戰鬥,機制上站得住(telegraph 節奏感是真的)。
- **無 FOMO 公約作為賣點**(不只是合規)— 「敢於無聊」若被正確包裝,是對疲憊成年人的精準訴求(Canon 原話:「給疲憊的人暫時住進來的地方」)。
- **倫理溢價**:確定性、不可越獄、依賴壓力導向邊界支持 — 家長/媒體視角的護城河。

## 可能讓它無聊的

- **每個回饋都是又一行安靜的散文。** 品質再高,第 40 行時邊際效果趨零。NOT VERIFIED(需真人長測),但風險結構明確。
- 無聲 + 無驚喜 + 無主動 = 第三天回來時,湖還是那個湖,貓還是等你先開口的貓。
- 對峙藏在一個地圖節點後面,多數玩家可能從未見過本作最原創的系統。UNKNOWN(無漏斗數據)。

## 1. 前三分鐘

- **知道要做什麼嗎?** 是 — 2026-07-03 修復後,光環→提示三段→溫柔邀請的串線完整。NOT VERIFIED(真機)。
- **夥伴看起來活著嗎?** 一半。有 idle 動畫和觸碰身體語言;但兩次互動之間牠只是站著。「活著」需要偶爾自主的微動作。
- **摸/說/照顧有即時回饋嗎?** 視覺+文字:有。聲音:**全部沒有**。
- **世界回應了嗎?** 痕跡微光會出現(好),首痕文案優秀 — 但很微弱,且無聲。
- **困惑/無聊點:** (a) guidance 步先講三條哲學契約再讓你摸貓 — 誠實,但「體驗前的宣言」有說教風險;建議在 meet 步補**一句懸念承諾**(現有文案只有安撫,沒有好奇鉤)。(b) 無聲讓一切像 mock-up。(c) trust 數字無解釋。

## 2. 核心循環

實際循環:**摸/說/照顧 → 數值漂移+痕跡 → 里程碑句 →(偶爾)探索 →(罕見)對峙**。
- 性質:情緒-文字型。機制深度只存在於對峙;視覺回饋薄,聽覺回饋零。
- 每動作有可見回饋?文字必有,視覺部分有(痕跡/動畫),聲音無。
- **和「有按鈕的聊天室」差在哪?** 真差異存在:狀態驅動的拒絕、持久痕跡、邊界經濟。但這些差異目前**用氣音說話** — 不主動的夥伴+無聲反饋讓多數玩家把它體驗成「發訊息給一個溫柔的 bot」。差異需要被舞台化,不是被暗示。

## 4. AI 使用批判

- **真高價值**:RaphaelCore 確定性管線(這就是產品脊柱)、eval/release gate(撐起出貨紀律)、Nuwa 靜態蒸餾(便宜、安全、剛通過 TP-1A)。
- **過度工程**:見上文「過度工程的」四項。
- **應該保持確定性/模板/簡單規則的**:**心語回應本身** — 不要追 LLM 感。當前瓶頸是行數(84 基礎行)和主動時刻(0 個),不是回應智能。規則式回應是特性(可審、可測、不會翻車),不是恥辱。
- **Fable 5 只做開發審計員**:本類審計、TP-7 行為清單的紅線審查、高風險 diff 的 fresh-context review、eval 設計。
- **永遠不進 runtime 的**:玩家向回應生成、NPC 對話、runtime 情緒分類 — canon 紅線 + 成本 + 安全三重否決,無需再議。

## 5. 商業品質

**仍是原型感(陽春)的**:無聲(+死滑桿)、圖鑑佔位、敵人無臉、探索瞬間文字、content-tier 中文殘留於 EN 模式（i18n sc/jp 252×4 已驗證零缺漏，見 docs/qa/verify_i18n_strings.mjs）。
**20% 改動 → 80% 觀感**(按序):
1. 音效包(6-10 個 SFX + 1 條環境音)— 單項最大觀感躍遷
2. 夥伴主動微時刻(用現成自主基建)
3. 對峙噪音 VFX(**復用**現成 `glitch_noise`/trace 渲染,零新系統)
4. 探索兩拍化(結果前 1-2 秒棲地反應)
5. 死 UI 誠實化(藏 SFX 滑桿直到接線;圖鑑鈕標「尚未開放」或接 Linkara 圖)

**Steam/App 可打包垂直切片前必須**:上述 1-5 + Initial Bond 決策(見 TP-8)+ 30 分鐘弧(第一章節拍)+ 已列的人類 gate(真機/三測試者/法務)。

## 6. 好玩與情感投入

- **好奇鉤**:「牠會拒絕我嗎」「我的話留下了什麼」— 真實但**沒被宣傳**;開場沒有任何一句話承諾懸念。裂隙是現成的世界懸念,首輪不可見。
- **情感回報**:里程碑句、尊重獎勵、回歸文案 — 品質高、密度低。
- **驚喜**:結構性缺席(確定性反應+固定結果池+無稀有事件)。
- **無 FOMO 的進度感**:羈絆里程碑(12/25/45/70/90)+ 進化三階 — 骨架好,非懲罰性,合格。
- **玩家為何自願回來**:回歸文案真的溫柔、痕跡衰減給了「上次的光還在」的軟理由 — 但**離線期間什麼都不會發生**(旅痕未實裝),第三天的湖=第一天的湖。NOT VERIFIED(需縱向真人數據),風險結構明確。
