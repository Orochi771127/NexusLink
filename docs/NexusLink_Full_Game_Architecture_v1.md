## 2. 遊戲核心定位

### 2.1 一句話定位

《Nexus Link》是一款情緒棲地型 AI 夥伴養成遊戲。玩家不是單純養怪獸，而是在一個會記住他、回應他，並隨著互動改變的數位棲居空間中，與具有邊界、記憶與人格差異的 AI 生命建立關係。

### 2.2 核心標語

> 養成的不是怪獸，而是一段會記得你的關係。

### 2.3 產品本質

《Nexus Link》不是一般 AI 聊天室，也不是純戰鬥 RPG。它的本質是：

```text
AI 情感陪伴
+ 電子寵物
+ 情緒棲地
+ 輕度養成
+ 角色人格矩陣
+ 長期記憶
+ 低壓力探索
+ 未來可擴展戰鬥系統
```

### 2.4 與一般 AI 伴侶的差異

一般 AI 伴侶常見問題：

- 太像聊天室。
- 長期新鮮感下降。
- 角色過度順從。
- 玩家沒有真正感覺到「牠有自己」。
- 所有互動停留在文字。

《Nexus Link》的差異：

- 主畫面是一個棲地，不是聊天室。
- 角色有身體、有動畫、有呼吸。
- 角色有防衛閾值，不會永遠順從。
- 數值隱性化，透過動作、環境與台詞表達。
- 玩家離開後，世界會留下情緒痕跡。
- 玩家回來時，角色會根據時間、記憶與信任做出不同反應。
- 多角色不是單純換皮，而是有不同人格係數與依附風格。

## 3. 目標玩家

### 3.1 核心族群

1. **高比例獨處者**：自由工作者、遠距工作者、夜班者、工程師、創作者。這類玩家不一定沒有社交，但缺少穩定被理解的空間。
2. **情緒沉浸型玩家**：喜歡《Sky 光遇》、《風之旅人》、《動物森友會》、《星露谷物語》等低壓力陪伴型體驗的人。
3. **養成投射型玩家**：會把寶可夢、數碼獸、電子寵物、AI 角色視為朋友或陪伴對象的人。
4. **壓力與低潮玩家**：不一定需要醫療介入，但需要一個可以暫時安放情緒、不被現實評價的空間。
5. **創作者**：需要情緒場景、角色人格與世界觀刺激創作靈感的人。

### 3.2 不應優先瞄準的玩家

短期內不應優先服務：

- 只追求硬核戰鬥數值的玩家。
- 只要高效率工具 AI 的使用者。
- 只想刷任務、刷裝備、刷排名的玩家。
- 需要明確醫療療效的人。

> 《Nexus Link》可以具有療癒感，但現階段不應自稱心理治療或數位療法。

## 4. 完成版遊戲全貌

完成版《Nexus Link》應該是一個玩家打開手機或網頁後即可進入的全畫面情緒棲地。背景可能是夜間湖畔、森林神殿、星光聖域或水晶湖泊。中央有玩家自己的心核夥伴，例如灰影貓、焰尾狐、水晶海馬、雷霆幼狼等。

這些角色不是靜態圖片，而是有呼吸、有眨眼、有情緒距離、有互動反應的數位生命。

常駐 UI 應維持低干擾：

- 左上 compact HUD。
- 右上資源與設定。
- 中央夥伴。
- 小型 Soul Talk 入口。
- 底部四個主功能：探索、照顧、成長、記憶。

玩家可以輕觸角色。角色會根據狀態反應：

- 信任高時放鬆。
- 防衛高時後退。
- 太久沒回來時疏離。
- 過度觸碰時拒絕。
- 第一次觸碰時緊張但可能接受。

玩家也可以進入 Soul Talk。未來接入 AI 後，角色會根據 Raphael 人格核心、玩家語意、情緒狀態與記憶節點回應。

探索可以獲得記憶碎片、小物、棲地留痕。照顧可以安撫角色、餵食、休息、淨化。成長可以查看同步狀態、解鎖能力、準備進化。記憶可以保存對話片段、關係節點與重要回憶。

角色會逐漸成長甚至進化。但進化不是單純換外觀，而是反映玩家與牠之間的關係歷史。

## 5. 遊戲主循環

### 5.1 最小核心循環

```text
打開遊戲
→ 看到夥伴與棲地狀態
→ 選擇互動：摸摸 / Soul Talk / 照顧 / 探索 / 成長 / 記憶
→ 系統根據隱性狀態判斷反應
→ 角色用動畫、文字、音效、環境變化回應
→ 狀態與記憶保存
→ 下次回來時，世界與角色延續之前的關係
```

### 5.2 長期循環

```text
日常互動
→ 信任與羈絆累積
→ 記憶節點形成
→ 棲地發生留痕
→ 角色人格更穩定
→ 進入成長 / 淨化 / 進化事件
→ 解鎖新動畫、新台詞、新棲地、新能力
```

### 6.1 主畫面原則

首頁不是功能選單，而是情緒棲地。

主畫面必須保留：

- 角色完整可見。
- 背景是全畫面棲地。
- UI 低干擾。
- 不常駐大型聊天框。
- 不顯示過多硬數值。

## 7. 角色系統

### 7.1 角色不是換皮，而是人格矩陣

每隻角色都擁有：

- 外觀。
- 元素屬性。
- 依附風格。
- 防衛係數。
- 信任權重。
- 疲勞敏感度。
- 離線熵增速度。
- 專屬台詞。
- 專屬動畫語意。
- 專屬棲地偏好。

### 7.2 第一隻角色：灰影貓

**定位：** 慢熟、防衛、安靜觀察、界線感強。

灰影貓不是普通可愛寵物。牠的核心魅力是：

> 牠不會立刻相信你，但牠會慢慢記得你。

| 面向 | 灰影貓 |
|---|---|
| 依附風格 | 迴避 / 防衛 |
| 初始態度 | 觀察 |
| 接觸反應 | 緊張但可接受 |
| 過度觸碰 | 退後 |
| 長期離線 | 疏離 |
| 高信任時 | 安靜放鬆 |

### 7.3 第二隻角色：焰尾狐

**定位：** 熱情、黏人、焦慮型依附、怕被丟下。

焰尾狐和灰影貓相反。灰影貓是「慢慢靠近」，焰尾狐是「很想靠近，但容易焦慮」。

| 面向 | 焰尾狐 |
|---|---|
| 依附風格 | 焦慮 / 黏人 |
| 初始態度 | 熱情 |
| 接觸反應 | 容易接受 |
| 過度觸碰 | 情緒過載 |
| 長期離線 | 焦慮 |
| 高信任時 | 主動親近 |

## 8. 防衛閾值系統

### 8.1 目的

防衛閾值讓角色不會永遠順從玩家。

這不是為了懲罰玩家，而是讓玩家感覺：

> 牠是一個有界線的生命。

### 8.2 底層狀態

目前核心欄位包括：

```text
bond
trust
mood
energy
defense
touchFatigue
lastTouchAt
lastSeenAt
firstTouchCompleted
reactionPreview
chatHistory
```

### 8.3 反應結果

| 結果 | 意義 |
|---|---|
| accept | 接受 |
| guarded_accept | 緊張但接受 |
| hesitate | 猶豫 |
| reject | 拒絕 |

### 8.4 設計原則

玩家不應直接看到：

```text
defense = 65
touchFatigue = 9
delta = -24
```

玩家應看到：

```text
灰影貓耳朵動了動，但沒有躲開。
灰影貓默默往後退了一點。
灰影貓看著你，尾巴末端有些緊繃。
```

## 9. 隱性狀態設計

### 9.1 原則

數值存在於底層，感受顯示於畫面。

不要讓玩家玩成 Excel。要讓玩家透過角色狀態與環境變化理解關係。

### 9.2 表現方式

| 狀態 | 表現 |
|---|---|
| calm | 穩定呼吸 |
| defensive | 耳朵後壓、身體收緊 |
| distant | 位置後退、呼吸變慢 |
| happy | 眼神放鬆、微光加強 |
| tired | 睡姿、低亮度 |
| corrupted | glitch、黑霧 |
| purified | 藍白光、心核穩定 |

## 15. 記憶系統

### 15.1 目的

記憶系統是《Nexus Link》的核心差異化。玩家不是只和 AI 對話，而是共同累積一段關係。

### 15.2 記憶類型

| 類型 | 內容 |
|---|---|
| 對話記憶 | 重要文字 |
| 互動記憶 | 第一次摸摸 |
| 情緒記憶 | 防衛 / 安撫 |
| 探索記憶 | 發現事件 |
| 進化記憶 | 成長節點 |
| 重逢記憶 | 久別回來 |

### 15.3 心核渡引經

```text

重建心核
顯示刻印時間
```

文案：

> 此為心核渡引經。若世界重置，憑此印記仍可再度相逢。

## 19. 成長與進化系統

### 19.1 成長不只是等級

成長應包含：

- 同步率。

## 25. 最終產品願景

完成版《Nexus Link》是一個玩家可以長期回來的數位棲地。

它不是每天逼玩家打卡，也不是用任務壓迫玩家。它是一個在玩家生活縫隙裡存在的地方。

玩家可以深夜打開它，看到灰影貓安靜地坐在湖邊。牠可能不會立刻靠近，但牠會記得你。你可以摸牠，牠可能緊張、可能接受、可能後退。你可以和牠說話，牠會逐漸理解你。你離開幾天後回來，世界會有變化。牠不會責怪你，但距離會留下痕跡。你們可以慢慢重新靠近。

這就是《Nexus Link》的核心：

> 一款會記住你、也會和你保持距離的 AI 夥伴遊戲。

真正的賣點不是 AI 技術本身，而是：

> 讓玩家感覺有一個數位生命，在某個安靜的地方，持續地與他建立關係。
